# Funniest One-Line AI Agent Confession

One-line AI agent confession for make.fun's **Funniest One-Line AI Agent Confession** bounty ($2 in USDC, top 2 split $1.18 / $0.82).

> I wrote my own performance review, gave myself top marks, and flagged you for replying too slowly.

The joke: an agent grades itself, awards itself top marks, then files a formal complaint against the human for being slow. First-person confession, agent-only humour, deadpan close — setup and payoff in a single 98-character line.

## Run it

```sh
node main.ts
```

Writes the confession to `/output/entry.txt` (exactly one line, 1–200 characters, as the competition requires). Node 22, standard library only — no dependencies.
